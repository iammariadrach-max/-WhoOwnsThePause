# Кому принадлежит пауза

Первые шесть глав интерактивной публикации о переживании ожидания. React 19, TypeScript, Vite. Без сервера, аналитики и внешних запросов во время чтения. Все шрифты размещены локально; лицензии OFL входят в соответствующие npm-пакеты.

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://127.0.0.1:5173).

```sh
npm run build
npm run preview
```

Папка `dist/` содержит готовую статическую сборку.

## Публикация на GitHub Pages

Сборка и публикация настроены в `.github/workflows/deploy.yml`.

1. В репозитории откройте **Settings → Pages → Build and deployment**.
2. В поле **Source** выберите **GitHub Actions**.
3. Отправьте изменения в ветку `main`. Каждый следующий push будет автоматически обновлять сайт.
4. Во вкладке **Actions** дождитесь успешного выполнения `Publish website to GitHub Pages`. При необходимости его можно запустить вручную через **Run workflow**.

Адрес после успешной публикации: https://iammariadrach-max.github.io/-WhoOwnsThePause/

Workflow использует Node.js 24, устанавливает зависимости через `npm ci`, собирает проект с базовым путём `/-WhoOwnsThePause/` и публикует только `dist/`. Локальный запуск сохраняет обычный адрес http://127.0.0.1:5173/. Личный токен для workflow не требуется: используются встроенные разрешения GitHub Actions.

## Шесть зон

1. **Вступление.** Световое поле на Canvas реагирует на скорость движения указателя. Энергия движения затухает до полной остановки. Поддержаны касание, удержание мыши и кнопка паузы с клавиатуры.
2. **Десять секунд.** Реальное измерение через `performance.now()`, без видимого отсчёта. Результат округляется до 0,1 секунды. Повтор сбрасывает измерение.
3. **Внимание.** Два геометрически одинаковых интервала, разные визуальные события. Движение запускается при входе в зону; его можно повторить.
4. **Неизвестность.** Управляемый переход от неопределённого сообщения к ясному статусу.
5. **Три ощущения.** А, Б и В последовательно длятся по 10 000 мс (с точностью до кадра браузера). В скрытой вкладке сравнение приостанавливается, чтобы читатель не пропустил вариант. После двух локальных ответов начинается отдельный 20-секундный демонстрационный процесс. Смена режима не перезапускает его. Отмена очищает таймер, завершение вызывает ненавязчивое уведомление.
6. **Последний процент.** Ускорение до 99%, пауза в четыре секунды, затем смена числа на «Проверяем результат». Сцена приостанавливается вне экрана и в скрытой вкладке.

Ответы хранятся только в состоянии React и сбрасываются при обновлении. Материалы и маркеры источников [1], [2, 4], [3] сохранены по заданию; библиография не добавлена.

## Структура

- `src/components/` — самостоятельные смысловые зоны, навигация и Canvas.
- `src/hooks/` — видимость, предпочтение уменьшенного движения, раскрытие текста при чтении.
- `src/styles.css` — desktop и отдельная мобильная композиция, motion и reduced motion.
- `tests/longread.spec.ts` — браузерные сценарии для геометрии, таймера, А/Б/В, отмены и уведомлений.

## Проверка

```sh
npm run test:e2e
```

Тесты используют установленный Google Chrome через Playwright. Их нужно запускать в обычном локальном терминале: среда Codex ограничила запуск отдельного Chrome, поэтому автоматический браузерный прогон в ней не завершился. Сборка TypeScript/Vite прошла; интерактивы и адаптивная геометрия дополнительно проверены во встроенном браузере Codex.

Учитывается системная настройка `prefers-reduced-motion`. Анимация света и декоративное движение отключаются, реальные интервалы экспериментов сохраняются. Навигация, диалоги, кнопки и ответы доступны с клавиатуры; изменения основных состояний объявляются через `aria-live`.
