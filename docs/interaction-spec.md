# Интерактивы

## Общие правила

Context + useReducer находится выше всех секций. Состояния не уничтожаются при прокрутке. Процесс содержит status, startedAt, duration и run. Deadline вычисляется из времени старта; setTimeout только будит проверку. Возвращение вкладки через visibilitychange/pageshow пересчитывает остаток. Запоздалое событие предыдущего run не может завершить новый процесс; cancelled не превращается в complete. Все timeout/interval/RAF и observers очищаются в cleanup.

Для субъективного замера используется performance.now(), результат хранится с полной точностью и показывается до 0,1с. Для процессов — performance.timeOrigin + performance.now(). Только файл зоны 04 сохраняется в localStorage; после новой загрузки сравнивается timestamp. При запрете storage работает текущая сессия. Изменение системных часов между закрытием и повторным открытием может повлиять на восстановленный демонстрационный deadline; внутри документа таймер монотонный.

Анимационные кадры progress меняют CSS variable через ref, без React state на каждом кадре. Countdown обновляет локальный текст с шагом 100ms; арифметика всегда от elapsed time. Фоновые процессы не зависят от IntersectionObserver. Декорация вне viewport не требует отрисовки.

## Reduced motion

Системное предпочтение слушается через matchMedia и обновляется при изменении. Поле — статичные 10 срезов, playhead скрыт, заголовок полностью читается. ETA одновременно содержит старое 7 и обновлённое 9. Fork показывает итоговые статичные модели; spinner становится неподвижным пунктирным кольцом. Перегруженное поле показывается без последовательного движения и очищается кнопкой. Все реальные таймеры сохраняют длительность и возможности пропуска. Режим pageMotionPaused отдельно от reducedMotion: пользователь не может случайно отменить системное предпочтение.

## Mobile

Все split-композиции читаются последовательно. ETA переходит на вертикальную линию. Fork: целиком модель А, затем модель Б, затем общий вопрос. Diagnostic — доступный accordion с теми же DOM-ответами. Sticky отключён до 700px. Нет hover-зависимых действий. 52px минимальная высота кнопок, текст 17px и выше.

## Screen reader и focus

Результат timer и bridge, завершение фоновых процессов, countdown и действия diagnostic объявляются через polite status. Секундные tick не зачитываются бесконечно. При выборе главы dialog закрывается, фокус ставится на секцию без дополнительной прокрутки. Escape возвращает фокус на opener. Источники — обычные ссылки; back-link указывает на конкретный вызвавший маркер. Keyboard: Tab, Shift+Tab, Enter/Space; radio работает нативно. Canvas содержит только декоративные символы. Все тексты и пользовательские действия остаются доступны в DOM без Canvas.

## Art direction — 20 октября 2026

Таймеры, reducer, авторский текст и состояния сохранены без изменения. Текущие четыре сцены и их reduced-motion варианты определены в `motion-map.md`. Финал повторно использует engine hero. Type Sediment накапливается 3,6с и исчезает за 1,6с; это декорация, не блокирующее ожидание. При page pause или reduced motion показывается статичное итоговое состояние. Lenis действует только на desktop wheel, уничтожается при паузе/системном reduced motion. Навигация сохраняет фокус и учитывает CSS scroll-padding ровно один раз.
