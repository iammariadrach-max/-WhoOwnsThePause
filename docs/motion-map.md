# Карта движения

> Историческая версия до 21 октября. Текущая обложка, фон и навигация описаны в [reference-cover.md](reference-cover.md).

Самостоятельных сложных сцен четыре: Hero + Elastic ETA + Type Sediment + Acceleration Fork. Finale повторно использует Hero engine и не считается пятым движком.

## Короткие связки

01→02: обложка переходит в два обычных вводных абзаца, затем в опыт с интервалом. 03→04: negative-полоска переводит восприятие в системный голос. 05→06: progress-line расширяется в масштаб процента. 06→07: линия продолжается в ETA. 08→II: остановленный timecode и пустой кадр. 09→10: физический осадок/тишина. 12→13: линия раздваивается. 14→15: зонды сходятся к оси.

Scroll-driven: только локальный progress CSS и малое смещение светового слоя. Никакого React setState на кадре и scrub абзацев. IntersectionObserver определяет соседние сцены; RAF затухает после остановки. Lenis — один scroll engine, без smooth touch. При reduced motion или page pause — native scroll.

Time-driven: реальные процессы остаются в прежнем provider/reducer. Декоративные интервалы не влияют на startedAt, duration, run или результаты. Зерно статично. Canvas DPR ограничен 1.5; ResizeObserver, IntersectionObserver, visibility handling и RAF очищаются при unmount. Основного текста в Canvas нет.
