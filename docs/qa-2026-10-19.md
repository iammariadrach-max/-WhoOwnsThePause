## Ограничения проверки

`npm run test:e2e` был запущен. Процесс Google Chrome завершается SIGABRT/EPERM до открытия страницы из-за локальной песочницы. Это блокировка запуска браузера, а не успешный e2e-прогон. Сценарии Playwright обновлены и включены в GitHub Actions перед публикацией; там используется Chromium с установкой системных зависимостей.

Режим prefers-reduced-motion проверен по реализации CSS/state и включён в автоматический браузерный тест, но отдельная эмуляция системного media preference во встроенном браузере недоступна. Пауза движения проверена фактически. Физический iPhone с Mobile Safari, screen reader VoiceOver/NVDA и профилировщик утечек памяти не запускались. Мобильная геометрия проверена во встроенном браузере, sticky на mobile отключён; aria, cleanup timers/observers/RAF и hidden-tab catch-up проверены по коду и timing tests. Это не заменяет проверку на реальном устройстве.

Библиографические сведения отсутствуют в исходных материалах; места источников явно помечены. Без них научные ссылки не считаются заполненной библиографией.
